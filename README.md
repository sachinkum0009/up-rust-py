This repository will contain Python language bindings to the [Eclipse uProtocol Rust Language Library]().
Developers can use these bindings to create uEntities in the Python programming language.

Note that these bindings are a wrapper around the existing Rust implementation of the uProtocol specification.
There still exists a [uProtocol Python Language Library](https://github.com/eclipse-uprotocol/up-python) which implements
the uProtocol specification from scatch. However, that repository is (currently) unmaintained and might eventually be
replaced by the bindings created in this repository.
