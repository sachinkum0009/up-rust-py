# Usage Guide

This guide demonstrates how to use `up-rust-py` for uProtocol communication in Python.

## Quick Start

Here's a simple example that demonstrates publishing and receiving messages:

### Simple Publisher (Local Transport)

For in-process communication without network overhead:

```bash
python examples/simple_publish.py

python examples/simple_notify.py
```
